# Escape Room Review Tracker v2.0.0 Cute Web

## Test before GitHub
Double-click `TEST-LOCAL.bat`.
It opens `http://localhost:8765`.
Keep the black server window open while testing.

`OPEN-DIRECTLY.bat` also opens the page directly, but the local-server test is closer to GitHub Pages.

## GitHub Pages
Upload:
- index.html
- style.css
- app.js
- manifest.json

No build step is required.

## Features
- Florence start/current/gained/goal/progress
- employee weekly/payroll/overall +/-
- uncredited Florence reviews
- employee leaderboard
- location leaderboard
- Stage Road, South Main, East Memphis, Amuse Adventure Museum, Game Nite Lounge preloaded
- separate Start New Week and Clear Payroll
- Undo up to 30 changes per session
- change history
- CSV export
- backup/restore JSON
- weekly and payroll archive browser
- Reconcile Florence Google total
- autosave to browser localStorage
- forest green, white, and gold theme

Important: employee-credited reviews do NOT increase the uncredited count. Uncredited is reserved for reviews with no employee credit.
